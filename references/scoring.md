# 买家与供应商评分（初筛用，不是采购意向证明）

## 买家匹配度（满分 100，≥60 才深挖并发信）

| 维度 | 分值 | 判断依据 |
|---|---|---|
| 主营与品类相关 | 0–30 | 官网在售目标品类 = 30；相邻品类 = 20；泛品类 = 10；无关 = 0 |
| 采购规模信号 | 0–20 | 进口商/批发商 = 20；连锁零售 = 15；电商卖家 = 10；规模不明 = 5 |
| 官网与业务真实性 | 0–20 | 官网正常、有在售产品、有公司信息 = 20；信息残缺酌减 |
| 公开商务联系方式可达 | 0–15 | 官网联系页/公开商务邮箱 = 15；只有表单 = 8；无 = 0 |
| 市场匹配 | 0–15 | 目标市场物流可达、无已知合规障碍 = 15；不确定 = 5 |

打分理由必须写进 buyers.csv 的 score_basis，一行一句，不许只填数字。

## 供应商核验（任一硬项不过，直接标「淘汰」）

硬项：型号与认证文件对得上（CE/FCC 须核对具体型号）；报价含阶梯价且有效期明确；MOQ、交期、售后责任书面可查。

软项（加分）：支持小批量/单件代发；有现货；回复询价 <24h；能提供实拍/检测资料。

原则：工厂自报的产能、认证、续航一律先记为「待核验」，核对文件后才改状态。

## 匹配逻辑（买家优先）

1. 买家回复三要素（主卖价格带、认证要求、试单量）后才形成真实需求单。
2. 拿需求单反向筛 suppliers.csv：品类对口 + 硬项全过 + 价格带覆盖需求，取前 2 到 3 家做短名单。
3. 短名单回给买家时附认证文件与核验结论，不只给价格。
